# Referencia de Design do Totem

Esta pasta guarda contexto persistente para futuras melhorias visuais do `/totem`.

Usar estes arquivos para orientar layout, hierarquia visual e decisoes de UX sem depender de repetir o mesmo prompt em toda sessao.

## Ordem de leitura recomendada
1. `visual-direction.md`
2. `accessibility-notes.md`
3. `future-references.md`

## O que esta pasta deve responder
- Qual sensacao visual o `/totem` deve transmitir
- O que precisa ficar mais claro para quem esta retirando a senha
- Quais restricoes de acessibilidade nunca podem ser perdidas
- Como avaliar a apresentacao visual da senha gerada

## O que esta pasta nao substitui
- `workflow/` continua sendo a fonte de verdade sobre estado do produto e progresso do projeto.
- O codigo atual continua sendo a referencia final para comportamento funcional.
